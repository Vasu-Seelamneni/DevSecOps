① Computer Fundamentals

  • Computer = Take the input → process the data → store the data → output
  • Core hardware, literally: CPU, RAM, HDD/Storage, NIC, GPU

💻 Your Laptop/PC

  • 2 CPU
  • 64 GB
  • 1 TB

🏢 Enterprise Server (Dell PowerEdge)

  • CPU → Xeon / AMD
  • RAM → 64 / 128 GB
  • NIC → 4 × 16 Gbps
  • Storage → 1 PB
Enterprise servers must be Reliable, High-Performance, Secure, 24/7, Redundant 🔁

② What is the Cloud?

The idea: Application / product software companies can rent servers from cloud providers and deploy applications over there — with high performance, high bandwidth, low latency on reliable & redundant infrastructure.

XAAS — Everything as a Service:
  • IAAS — Infrastructure as a Service (rent the physical server)
  • PAAS — Platform as a Service
  • SAAS — Software as a Service (Salesforce, Gmail, O365…)
  • Backup as a Service
  • Database as a Service
  • Storage as a Service

③ Datacenter Hierarchy 🏢

Virtual Servers (VM1, VM2, VM3…) ↑ Physical Servers ↑ Racks (Server rack) ↑ Datacenter = Availability Zone ↑ Region ↑ AWS + Azure (Global Infra)
Availability Zone = nothing but a physical datacenter. A region has multiple AZs (AZ-1, AZ-2, AZ-3).

A datacenter contains: ServersStorage devicesNW devices (switch)Cooling systemPower systemSecurity

Edge locations = CDN / Point of Presence (POP) near the customer's location — e.g. serving Blinkit users in West US from the nearest edge.

④ Software Stack on a Server

HW (CPU, RAM, NIC, Storage) → OS — Linux > 80–90%, Windows < 10% → SW Apps (.net, java, nginx, apache) → DB

Linux distros: RedhatFedoraUbuntuSuseKali

Core system knowledge needed: K8s, Docker, Java, Active Directory, DNS, DHCP, Linux/Shell, Python, Terraform

⑤ DevOps Goal 🎯

"DevOps Goal: Deliver the software at speed for the end users to use it."
Code➜ Git➜ Build (.jar/.war/.dll/.exe)➜ Test➜ Package (Docker)➜ Deploy (K8s / Cloud)➜ Monitor (Grafana)

DevOps = Development + Operations + Automation + Collaboration — build faster, deploy safely, keep it running.
