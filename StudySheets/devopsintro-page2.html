② AWS vs Azure — Key Ideas

  • Azure groups resources using Resource Groups (logical name/boundary for grouping a set of resources)
  • AWS uses Regions instead of Resource Groups to locate resources
  • Azure hierarchy: Root Management Group → Sub Management Groups → Subscriptions
  • Subscription = billing boundary (cost management + resources)
  • AWS identity = IAM (users, groups, policies) · Azure identity = Entra ID (users, groups, policies)
  • You can join Azure tenants, e.g. Citibank ↔ Citibank Loans
In AWS, instead of RG's it uses Regions.
