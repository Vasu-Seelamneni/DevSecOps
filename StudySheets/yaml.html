YAML — YAML Ain't Markup Language

My own notes, taken from the YAML Introduction diagram

① What is YAML?

YAML is a human-friendly, indentation-based way to organize data hierarchically.

It is a human-readable data serialization standard that can be used with all programming languages, and is often used to write configuration files.

YAML is designed to be easy to read and write — a popular choice for configuration management.

② Key Features

  • Human-Readable & Hierarchical — clean, structured, easy to scan
  • Flexible Datatypes — scalars (strings, integers, floats, booleans), lists, dictionaries (mappings)
  • Cross-Platform — works across different programming languages
  • Strict Indentation — XML/JSON don't need indentation, but YAML follows it strictly → more readable

③ JSON ↔ YAML

  • Every JSON file can be converted into YAML ✅
  • But NOT vice versa — features of YAML may be lost when converting YAML → JSON ⚠️

④ Common Uses

⚙️ Configuration Management

  • Ansible
  • Kubernetes
  • Docker Compose

📦 Other Uses

  • Data Storage — small amounts of data for ease of access & readability
  • Data Serialization — serialize data for communication between systems
  • Automation scripts — write automation scripts
  • Data exchange — between languages with different data structures

⑤ YAML Datatypes

Scalars: StringsIntegersFloatsBooleans

Collections: ListsDictionaries (Mappings)

⑥ Setup for Visualizing YAML 🛠️

# Install VS Code → Python → YAML extension pip3 install PyYAML pip3 install ruamel.yaml

Use these to observe YAML interpretation visually in Python.

⑦ Quick Recap ✍️

  • YAML = human-friendly, indentation-based data format
  • Used for config files (Ansible, K8s, Docker Compose)
  • JSON → YAML always works; YAML → JSON may lose features
  • Strict indentation = more readable
  • Cross-platform & language-agnostic
